Твои примеры.

Меняй объяснения и добавляй короткие видео прямо с телефона или компьютера. Посетители видят опубликованный результат.

Ключ используется только в этой вкладке и не сохраняется на сайте. После выхода или обновления страницы понадобится войти снова.

Как получить ключ для входа
  1. В GitHub открой Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Создай ключ для своего аккаунта, выбери только репозиторий Slangify и ограниченный срок действия.
  3. В Repository permissions включи Contents → Read and write. Остальные разрешения добавлять не нужно.
  4. Скопируй ключ в поле выше. Не отправляй его в чат и не публикуй.

Редактор проверяет аккаунт владельца. Публикацию разрешает GitHub — без доступа к репозиторию сохранить изменения нельзя.
